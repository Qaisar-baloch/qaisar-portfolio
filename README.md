# Qaisar Khan | Engineering Intelligence

Personal portfolio of **Qaisar Khan**, a Computer Science Engineering student at the University of Dunaújváros, Hungary, with a multidisciplinary background across electronics, satellite communications, data analytics and applied AI.

The portfolio brings these areas together in one interactive experience, highlighting professional engineering experience, selected projects, learning builds, technical skills and academic or competition achievements.

**Repository:** https://github.com/Qaisar-baloch/qaisar-portfolio

---

## Portfolio overview

The site uses a dark, cinematic visual system built around the idea of three connected technology fields:

- **Electronics:** embedded systems, sensors, hardware integration, CanSat engineering and satellite-related technical work.
- **Data:** data preparation, analysis, data modelling, Power BI dashboards and business intelligence.
- **AI systems:** practical applications using language models, retrieval-augmented generation (RAG), vector search and agentic workflows.

The hero section features a central portrait with independently animated Electronics, Data and AI Systems orbiting labels. The page is responsive and includes reduced-motion support.

## What the portfolio contains

1. **Hero / introduction** — engineering identity and the AI, Data and Electronics focus.
2. **Professional experience** — Sub Engineer experience in the Space Electronics Wing at SUPARCO, Karachi, Pakistan (March 2025–August 2026).
3. **Technology universe** — interactive Electronics, Data and AI areas with related tools and methods.
4. **Selected projects** — five featured projects:
   - ShopAI — an AI-assisted business assistant prototype for small shops.
   - The Qualified Path — a scholarship preparation and guidance web platform.
   - Cloudly SaaS Analytics — a Power BI analytics course project using a synthetic dataset.
   - PneumoScan — a chest X-ray application integrating an existing trained model; it is not presented as a clinically validated diagnostic tool.
   - Remote Sensing Communication CanSat — an embedded/aerospace team project in which Qaisar served as project lead and handled electronics, power-subsystem work, sensor integration and technical documentation.
5. **More Builds** — a compact list of additional AI productivity, RAG and agentic learning projects.
6. **Credentials** — selected competition recognition and completed certificates.
7. **About and education** — academic background and portrait.
8. **Toolkit** — grouped technical skills.
9. **Contact** — email and social links.

## Run locally

### Requirements

- Node.js with npm
- Git

### Setup

Clone the repository and install the dependencies:

```bash
git clone https://github.com/Qaisar-baloch/qaisar-portfolio.git
cd qaisar-portfolio
npm install
```

Start the local development server:

```bash
npm run dev
```

Vite prints the local address in the terminal, usually `http://localhost:5173/`.

## Production build

Run the TypeScript check and production build:

```bash
npm run build
```

Preview the generated production build locally:

```bash
npm run preview
```

The production output is generated in `dist/`.

## Updating portfolio content

Most of the personal content is maintained in:

`src/data/portfolio.ts`

This file exports the data used by the interface:

| Export | What it controls |
|---|---|
| `profile` | Name, headline, location, portrait path, email and social links |
| `featuredProjects` | Five featured project cards, descriptions, contributions, tags and links |
| `experience` | SUPARCO role, location, summary, responsibilities and tools |
| `learningProjects` | Additional learning builds, descriptions, repositories and demos |
| `technologySkills` | Tool tags displayed in each interactive technology panel |
| `skills` | Grouped toolkit cards |
| `achievements` | Competition awards and other recognition |
| `certifications` | Completed courses and certificates |

When adding or editing an item, preserve the existing TypeScript object structure and property names.

### Replacing the portrait

The profile portrait is stored in `public/images/`. The current data file points to:

```ts
portrait: '/images/qaisar-portrait.jpeg',
```

To replace it, put the new image in `public/images/` and update the `portrait` value in `src/data/portfolio.ts`. Both the hero portrait and the About section use this same profile path.

### Updating project links

Project URLs are maintained in `src/data/portfolio.ts`:

- Featured project links use the `links` array in each `featuredProjects` item.
- Additional project repository and demo URLs use the optional `repo` and `demo` properties in `learningProjects`.

Only add a live-demo link when the project is actually deployed and the URL is publicly accessible.

## Deployment

This is a Vite static frontend and can be deployed to a static hosting provider such as Vercel, Netlify or Cloudflare Pages.

Recommended Vercel build settings:

| Setting | Value |
|---|---|
| Framework preset | Vite |
| Build command | `npm run build` |
| Output directory | `dist` |
| Install command | `npm install` |

Connect the GitHub repository to the hosting provider and deploy the `main` branch. Subsequent pushes to the connected branch can trigger automatic deployments.

**Deployment status:** A deployment URL is not documented here yet. Add the verified public portfolio URL once the first production deployment is complete.

## Project notes and responsible presentation

- **CanSat:** a team project. The portfolio describes Qaisar's confirmed role and does not imply sole ownership of every subsystem.
- **PneumoScan:** the application integrates an existing trained model. It is an educational/portfolio project, not a medical device or clinically validated diagnostic service.
- **Cloudly:** uses synthetic data and is identified as a course project.
- **More Builds:** includes training-guided and experimental work. The list does not imply that every item has the same level of production maturity.
- **ShopAI:** the portfolio links to its source repository and supporting project documentation; a public live demo is not currently listed.
